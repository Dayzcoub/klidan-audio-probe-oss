# Security

Report suspected vulnerabilities privately through [GitHub Security
Advisories](https://github.com/Dayzcoub/klidan-audio-probe-oss/security/advisories/new),
not in a public issue. Include a minimal reproduction, affected
version/commit, impact and safe mitigation if known. If the advisory form is
temporarily unavailable, contact the repository owner through GitHub and do
not attach sensitive data to an issue or pull request.

Do not attach raw reports, installer logs, crash dumps or machine-specific
profiles. Redact usernames, paths, endpoint IDs, serials and tokens first.

This project is offline-first and does not require cloud login, activation or
telemetry. Security reports must not be used to request physical audio tests.

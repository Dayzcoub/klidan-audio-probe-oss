# Security

Do not publish suspected vulnerabilities, credentials, endpoint identifiers or
private diagnostic data in a public issue. Contact the project maintainer
through the repository owner's approved private channel and include a minimal
reproduction, affected version/commit, impact and safe mitigation if known.

Do not attach raw reports, installer logs, crash dumps or machine-specific
profiles. Redact usernames, paths, endpoint IDs, serials and tokens first.

This project is offline-first and does not require cloud login, activation or
telemetry. Security reports must not be used to request physical audio tests.

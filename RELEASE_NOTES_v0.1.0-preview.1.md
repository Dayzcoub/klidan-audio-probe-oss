# KLIDAN Audio Probe 0.1.0-preview.1

This is preview software for Windows 10/11 x64. Results are diagnostic
observations, not hardware certification or a promise of compatibility.

## Preview limitations

- The installer is unsigned. Windows SmartScreen or Defender may show a warning.
- No physical round-trip latency (RTL) certification is provided.
- `AudioHost` remains `NOT_CERTIFIED`.
- Physical audio QA was not performed during the L10N-5 final QA pass.
- Do not interpret Windows format support or software transport observations as
  measured acoustic or ADC/DAC latency.

The Final QA report records the checks, installer manifest, SHA-256, and
remaining live GUI discovery and DPI validation blockers. The QA installer is
not a published GitHub Release. No release or tag was created by this pass.
